# Архитектура Web UI (UI_ARCHITECTURE.md)

## 1. Введение и назначение

Web UI предоставляет визуальное, интерактивное и безопасное управление миграцией данных из WEEEK в Linear.
Интерфейс спроектирован по принципу **Mobile First** и стандартам современного веб-дизайна (**Linear / Vercel / Raycast**).

---

## 2. Структура компонентов

```
src/server/
├── server.ts             # WebServer: локальный HTTP сервер (node:http)
├── routes.ts             # ApiRouter & SseManager: REST API + SSE стриминг
├── types.ts              # DTO запросов, ответов и событий
└── public/
    ├── index.html        # Семантический каркас Mobile First
    ├── app.css           # Дизайн-система (Linear Dark, Glassmorphism, Анимации)
    └── app.js            # Реактивное SPA управление состоянием
```

---

## 3. Дизайн-система и UI/UX токены

### Цветовая палитра (Dark Mode)
- **Базовый фон**: `#0B0C0E`
- **Поверхности карточек**: `#12141A`
- **Приподнятые элементы**: `#1A1D26`
- **Акцентный цвет (Linear Purple)**: `#5E6AD2` (`#717DF2` hover)
- **Успех (Emerald Green)**: `#4EBA6F`
- **Предупреждение (Amber Orange)**: `#F2994A`
- **Ошибка (Coral Red)**: `#EB5757`

### Адаптивность и Mobile First
- Оптимизировано для мобильных устройств (iPhone SE 375px+), планшетов, ноутбуков (MacBook Air/Pro) и 4K мониторов.
- Все интерактивные элементы соответствуют стандарту $\ge 44 \times 44$ px.
- На мобильных устройствах исключены HTML-таблицы в пользу карточек с гибкой структурой.

### Состояния интерфейса
Каждый экран поддерживает 4 обязательных состояния:
1. **Loading**: скелетоны загрузки (`skeleton-card`) и спиннеры.
2. **Empty**: информативные пустые состояния с пояснениями.
3. **Error**: контрастные баннеры ошибок с возможностью повтора.
4. **Success**: карточки итогов и скачивание отчетов.

## 4. Спецификация REST API и SSE

| Метод | Путь | Назначение |
| :--- | :--- | :--- |
| `GET` | `/api/status` | Проверка статуса сервера и предзагрузка токенов из `.env` |
| `POST` | `/api/auth/test` | Тестирование токенов WEEEK и Linear |
| `GET` | `/api/weeek/projects` | Список проектов WEEEK со счетчиками задач |
| `GET` | `/api/linear/teams` | Список доступных команд Linear |
| `GET` | `/api/linear/states` | Список Workflow состояний для выбранной команды |
| `GET` | `/api/linear/users` | Список пользователей Linear |
| `POST` | `/api/migrate/start` | Запуск конвейера миграции |
| `POST` | `/api/migrate/stop` | Остановка текущего процесса миграции |
| `GET` | `/api/migrate/stream` | Поток событий Server-Sent Events (SSE) |
| `GET` | `/api/reports/latest` | Получение последнего сформированного отчета |
