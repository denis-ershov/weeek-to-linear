# Архитектура CLI и UI/UX (CLI_ARCHITECTURE.md)

## 1. Введение и стандарты UI/UX

CLI-интерфейс спроектирован по стандартам современных инструментов разработчика (Linear, Vercel, Supabase, Raycast) в соответствии с правилами проекта:
- Минималистичный и чистый интерфейс.
- Интуитивный интерактивный мастер (Wizard) с подсветкой выбора.
- Четкие индикаторы прогресса (`ora` спиннеры, `cli-progress` мульти-бары).
- Понятные и информативные сообщения об ошибках без технического шума.
- Поддержка как интерактивного, так и CI/автоматизированного режима (через флаги).

## 2. Команды CLI

### 1. `auth:test`
Проверка корректности токенов WEEEK и Linear и отображение подключенных рабочих пространств.
```bash
weeek-to-linear auth:test
```

### 2. `weeek:projects`
Получение и вывод списка проектов WEEEK с количеством задач.
```bash
weeek-to-linear weeek:projects
```

### 3. `linear:teams`
Вывод доступных команд Linear с их идентификаторами и ключами.
```bash
weeek-to-linear linear:teams
```

### 4. `migrate`
Основная команда запуска миграции.

#### Флаги:
- `--dry-run` — режим симуляции: валидация, подсчет сущностей и маппинг без создания объектов в Linear.
- `--resume` — продолжение незавершенной миграции на основе `.weeek-linear/state.json`.
- `--force` — принудительный запуск с подтверждением перезаписи существующего состояния.
- `--weeek-project <id>` — неинтерактивное указание ID проекта WEEEK.
- `--linear-team <key>` — неинтерактивное указание ключа команды Linear (например, `ENG`).
- `--log-level <level>` — уровень детализации логов (`trace`, `debug`, `info`, `warn`, `error`).
- `--include-completed <boolean>` — миграция завершенных задач (по умолчанию: `true`).
- `--include-deleted <boolean>` — миграция удаленных задач (по умолчанию: `false`).

## 3. Компоненты терминального интерфейса

1. **Brand Banner**: Аккуратный заголовок с названием утилиты и версией.
2. **Interactive Prompts**: Библиотека `@clack/prompts` для выбора проектов, команд и сопоставления сущностей.
3. **Table Formatter**: `cli-table3` с элегантными тонкими границами.
4. **Progress Bar**: `cli-progress` для отображения переноса задач в реальном времени.
5. **Summary Card**: Итоговая карточка со статистикой миграции и ссылкой на отчет.
