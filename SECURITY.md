# Политика безопасности (Security Policy)

| Версия | Поддержка |
| :--- | :--- |
| `0.3.x` | :white_check_mark: Активно поддерживается |
| `< 0.3.0` | :x: Устарела |

## Сообщение об уязвимости

Безопасность является ключевым приоритетом проекта **WEEEK → Linear Migration Tool**.

Если вы обнаружили уязвимость безопасности:
1. **НЕ создавайте публичный issue** на GitHub.
2. Отправьте конфиденциальное сообщение через [GitHub Security Advisories](https://github.com/denis-ershov/weeek-to-linear/security/advisories/new) или на почту мейнтейнера.
3. Опишите:
   - Тип и суть уязвимости.
   - Пошаговые инструкции для воспроизведения (PoC).
   - Потенциальные последствия.
   - Предлагаемые способы устранения (если есть).

Мы обязуемся предоставить первоначальный ответ в течение 48 часов и оперативно выпустить патч.

## Принципы безопасности инструмента

- **Zero Data Leak**: Утилита выполняется строго локально на вашей машине и не передаёт никакие данные на сторонние серверы, кроме официальных REST/GraphQL API WEEEK и Linear.
- **Маскирование секретов в логах**: Токены API (`WEEEK_API_TOKEN`, `LINEAR_API_TOKEN`) автоматически маскируются (`[REDACTED]`) в журналах вывода и никогда не сохраняются в файле состояния `.weeek-linear/state.json` или отчётах.
- **Безопасность локального Web UI**:
  - Токены хранятся исключительно в оперативной памяти активной сессии браузера и сервера Node.js.
  - Ограничение размера входного запроса (1MB) для защиты от DOS.
  - Отсутствие сторонних трекеров, аналитики и CDN — весь UI работает автономно без внешних подключений.
- **Шифрование при передаче**: Все взаимодействия с API WEEEK и Linear выполняются строго по защищенному протоколу HTTPS (TLS 1.2+ / TLS 1.3).
